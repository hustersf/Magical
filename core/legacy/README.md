# :core:legacy 模块规范

### 📌 状态
* **Legacy（遗留模块）**

### 🎯 用途
存放历史 App 仍在使用，但新架构已废弃的公共代码与资源。

### ⛔ 原则
1. **允许修 Bug**：仅限修复现有逻辑的线上缺陷。
2. **允许兼容性修改**：仅限适配新版 Android SDK 或 Gradle 插件。
3. **禁止新增功能**：严禁在此模块添加任何新业务或新需求。
4. **禁止新模块依赖**：所有新增的业务组件及新 App 壳工程，严禁依赖此模块。
5. **禁止继续向该模块迁入代码**：严禁将其他老旧模块的废弃代码往此处迁移。

### 🏳️ 目标
逐步迁移或删除，最终彻底下线。
